# 找媽媽 V2：回家的四盞燈

保留原版四章故事、支線、居民日常、送貨、滑板車、環道計時與逐句配音，新增統一鍵盤操作、自訂名稱、即時森林事件，以及透視鏡頭與材質改善。原版 `find_mom_3d` 沒有修改；首頁同時提供兩個版本。

## 開始遊玩

在專案根目錄執行 `node tools/serve.cjs`，開啟 <http://127.0.0.1:4174/find_mom_3d_v2/>。也能從遊戲小花園選「找媽媽 V2」。遊戲資源全部在本機，不需要外部圖片、模型或網路服務。

| 操作 | 功能 |
| --- | --- |
| 方向鍵 | 探索移動；選單、角色與台詞選擇；風管按格移動；即時挑戰左右控制 |
| 空白鍵 | 出發、確認、交談、旋轉風管、放置回憶、敲風鈴、跳河、修橋、煞船、拍照、求援；遇蚊子揮手、近猴子互動 |
| Esc | 開啟／離開暫停選單；關閉設定視窗；文字輸入時先結束編輯 |
| S（選用） | 手持包裹時放下，騎滑板車時響鈴；同樣功能可用 Esc 選單完成 |
| 手機 | 搖桿移動，互動鈕操作；蚊子事件時互動鈕顯示「揮手」 |

探索預設輕快跑步，可從 Esc 選單改成散步，不必按住 Shift。按鍵選到文字欄位後，空白鍵開始編輯；名稱與搜尋需要一般文字輸入。錄音許可與檔案匯入仍使用瀏覽器的原生視窗。

## 清爽畫面與手機操作

小地圖只顯示玩家、目前目標與已開放出口，移除居民、玩具、鎖住的出口、賽道旗幟與下方的路線按鈕；地形依世界邊界緊密繪製。四關路線、出口指引、水果／事件統計和操作小抄，集中在 Esc 選單的「遊戲資訊」，主動點開才顯示。

遊戲場景固定在一個畫面，頁面不會產生水平或垂直捲軸。暫停選單預設精簡；當下不能使用的放下、響鈴、退出挑戰也不占空間。「其他設定」預設折疊，包含角色名稱、配音及畫質等項目。資訊視窗與展開的設定內容才允許內部捲動，關閉後返回原本畫面，重新暫停時再次折疊。這些入口可用滑鼠／觸控打開，也保留方向鍵與空白鍵操作。

手機搖桿與互動鈕預留至少 48 px 的左右及下方距離，再加上裝置安全區；直向的下方距離隨畫面高度增加，橫向保持兩側對稱的拇指操作位置。滑板車響鈴與速度表跟著相同位置更新。

## 原版分析與優化清單

原版的優點是四章故事、不同挑戰與大量可選互動已完整，逐句錄音也已有儲存、備份與錯誤處理。因此 V2 延續內容，集中改善下列問題。

| 目標 | 原版觀察 | V2 已實作 | 驗收方式 |
| --- | --- | --- | --- |
| 1. 更好玩 | 主線挑戰種類很多，但大地圖主要依賴玩家主動尋找互動；事件與探索回饋不足 | 每區六顆水果、偶發蚊子與猴子、收集與機智應對紀錄、即時提示、短失誤後恢復；保留主線與自由活動 | 四章主線挑戰成功，收集／防禦／追回水果流程成功；趣味程度需玩家試玩判斷 |
| 2. 主要只用方向鍵、空白鍵、Esc | 原版 Input、ActionTrials、Sandbox 與各種 UI 各自接收鍵盤；選單多靠 Tab，部分解謎靠滑鼠 | 一個鍵盤路由依遊戲模式處理動作；方向鍵導覽所有選單、題目與台詞；空白鍵只執行一次當前動作；Esc 選單包含任務、筆記、配音、設定及輔助操作 | 測試用這三種按鍵完成四章挑戰、故事求援、任務追蹤、錄音與設定 |

| 4. 更有 3D 感與質感 | 正交相機弱化近大遠小；多數材料使用相同粗糙度 | 42° 透視鏡頭、跟隨距離依視窗比例調整、較平滑角色球面、木紋與細微凹凸、預濾環境反射、冷色補光、柔和陰影、霧與樹冠遮擋淡化；手機預設流暢畫質，可選精緻 | 桌機、手機直向／橫向與小尺寸截圖檢視；相機、畫布大小與縮放測試 |
| 5. 減少 bug | 多個鍵盤監聽器容易同時處理空白鍵；新增事件容易污染存檔或持續在暫停時運作 | 集中輸入；限制單一事件；事件使用獨立時鐘；暫停、對話、解謎、換圖安全處理；水果可退回且不更改任務物品；保存失敗仍可玩；WebGL 中斷顯示恢復提示 | 真實瀏覽器整合測試、受限儲存、WebGL 中斷、換圖退款、事件凍結；原有碰撞小步掃描與存點保留 |
| 6. 自訂任何角色名稱與配音 | 原版有 45 位角色、627 句逐句配音，缺少名稱編輯；直接修改角色 ID 會破壞劇本和錄音 | 47 位角色、635 句可錄台詞（含猴子與蚊子）；名稱獨立存放；畫面呈現替換名稱，劇本角色 ID 與音檔鍵不變；保留錄音、試聽、重錄、匯入匯出 | 改名後對話、保存／重載與錄音播放；實際 MediaRecorder 儲存、取消、麥克風拒絕與備份測試 |
| 7. 更像即時遊戲 | 原版即時挑戰主要在固定入口開始，探索中的威脅較少 | 探索約 24 秒後開始可能事件，事件間隔約 28～48 秒；蚊子先預警、可揮手或移動避開，錯過會短暫減速；猴子會走近搶一顆水果、逃跑，可追上或拾回，未取回會由朋友送還 | 自動觸發、防禦、搶走／追回、短暫減速／恢復、手機揮手、暫停及閱讀期間凍結測試 |

這裡的「更好玩」是已落地的玩法改進，不等於已取得兒童玩家的偏好評分。測試確認能玩、能過關與功能行為；節奏及趣味仍可依實際試玩回饋微調。

## 角色名稱與配音

封面或 Esc 選單都有「角色名稱」與「角色配音」。每位角色可設定 1～12 個字的名稱。名稱會套用到對話、筆記、任務提示、角色標示與配音室；還原名稱不會刪掉音檔。

名稱、遊戲進度與水果紀錄分開保存於瀏覽器；V2 冒險進度使用獨立儲存鍵，不會覆寫原版存檔。角色與原句作為錄音識別，原版已錄的相同台詞仍可使用。改名不會把錄音配給別人，也不會破壞主線判定。

錄音保存在此瀏覽器的 IndexedDB，不上傳。每句上限 30 秒，重錄或儲存失敗會保留舊音檔。關閉配音室、切換分頁與離開頁面會關閉麥克風。可以匯出 JSON 備份再匯入其他裝置。錄音需支援麥克風 API 的瀏覽器以及 localhost 或 HTTPS；不同實體麥克風尚未逐台驗證。

## 即時事件規則

水果是可選收集，和主線光花、旅途物品、包裹分開。猴子不會搶主線物品，不會扣掉故事進度；搶水果後地面指引及小地圖目標轉向水果，結束後恢復原路線。換地圖、重新開始或關閉事件會退回尚未拿回的水果；中途重新整理也保留可退還的水果。

同時最多發生一件事件。對話、解謎、配音、暫停、計時環道、滑板車與坐下時不會新增事件；離開探索模式，進行中的事件計時停止，模型暫時隱藏。蚊子反應窗口約十秒；錯過只短暫慢走，不會死亡或重玩關卡。猴子的水果最多約 28 秒就會歸還，避免不必要的挫折。Esc 選單可關閉即時事件。

## 驗證與維護

需先啟動本機預覽，並安裝專案的 Playwright 測試依賴。Windows 預設使用 Microsoft Edge。

```sh
npm install
npm run test:find-mom-v2
```

也可以直接執行：

```sh
node find_mom_3d_v2/tools/build-voice-catalog.cjs --check
node tools/qa-find-mom-v2.cjs
node tools/qa-find-mom-v2-interface.cjs
```

可分別測試 `core`、`chapters`、`voice`、`layout`。輸出與截圖在忽略版控的 `.qa/find-mom-v2/`。測試錄音使用瀏覽器合成麥克風，不使用玩家的真實麥克風。

介面測試另外涵蓋 1440×900、390×844、320×568、844×390、667×375、568×320：檢查整頁與場景尺寸、實際滾輪操作、資訊與設定的明確展開／收起、搖桿拖曳、觸控驅蚊、方向鍵開啟改名、小地圖留白、手機轉向及首頁 V1／V2 分開的有效入口。

較長故事的前置里程碑使用預設存檔到達，再用實際方向鍵／空白鍵完成即時挑戰；不宣稱每張大地圖的每條探索路線都由測試徒步走完。手機是瀏覽器模擬，仍需實機手感確認。

修改對話後執行 `node find_mom_3d_v2/tools/build-voice-catalog.cjs`，再執行 `--check`。產生器會執行原有劇情分支並收錄事件台詞；姓名顯示與錄音鍵維持分離。

本次修復的實際測試問題包括：文字欄位卡住方向鍵導覽、任務視窗關閉與 Esc 的時序競爭、事件台詞分頁後音檔找不到，以及暫停中角色名稱更新被遊戲時鐘阻擋。

2026-10-05 驗收：新版完整 `all` 測試通過；補充的全螢幕鍵盤操作、靠近 NPC 時以觸控驅蚊、麥克風取消與受限儲存測試通過；台詞目錄同步檢查通過。六種尺寸的介面測試通過，包括實際滾輪、明確展開資訊、預設折疊設定、手機控制距離、騎滑板車時的精簡選單與轉向。原有 `tools/verify.cjs` 也通過，包括首頁 18 個入口與 16 款遊戲的核心回歸。測試未出現瀏覽器程式或資源載入錯誤。
