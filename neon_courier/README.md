# 霓光快遞：極速夜航 / NEON COURIER

為 16～20 歲玩家設計的 3D 即時角色扮演與高速配送遊戲。扮演夜班快遞員，在霓虹街區、雲端花園、星港天際之間駕駛浮板，把演出音軌、夜光種子、首映邀請函等包裹送到收件人手中。獨立的新遊戲入口，不修改找媽媽的任何版本。

## 遊戲設計

- **速度與技巧**：角色自動前進，三條航道切換、跳躍、衝刺與緩行；靠光環連段提高積分倍率，最高 ×5。較高的光環與越障獎勵鼓勵掌握跳躍時機。
- **角色扮演**：可自訂代號，選疾風、躍動、共鳴三種專長；三種委託各有三位收件人、不同包裹與通訊。累積經驗升級，分配永久技能點，建立自己的玩法。
- **即時變化**：順風航道加速、磁力潮汐擴大收集範圍、追光時刻加倍積分。每次委託重新生成路線，同一組障礙至少保留一條可通行航道，交付點前後保留 100 公尺障礙緩衝。
- **無血腥、無暴力**：沒有攻擊、武器、敵人、生命值或傷亡。維修設施只是路線挑戰，碰到時短暫減速、減少能量並中斷連段；錯過包裹由接駁機接手，玩家繼續下一站。刺激感來自速度、倒數、連段與路線決策。
- **3D 表現**：透視追蹤相機、平滑換道、角色傾斜、浮板尾流、立體城市、航道彎曲、霧化遠景、星空與發光招牌。物件池與 InstancedMesh 重複使用場景物件，手機限制像素密度以控制繪圖負擔。減少動態效果偏好會取消衝刺視角拉伸與尾流。

## 委託與成長

| 委託 | 長度 | 起始時間 | 特點 |
| --- | --- | --- | --- |
| 夜市補給 | 2.4 km | 108 秒 | 暖身，障礙間隔較大 |
| 屋頂派對 | 2.7 km | 100 秒 | 標準，連段與衝刺的平衡 |
| 星港首映 | 3.0 km | 98 秒 | 進階，路線判斷更密集 |

每次正確穿過交付光門增加 4 秒與 30 點能量。衝刺消耗能量，不衝刺時自動回充；耗盡後需恢復到 25 點才重新啟用，避免零能量時速度抖動。疾風速度較快、耗能較低；躍動可以二段跳；共鳴的收集範圍較大、回充較快。

每 220 XP 升級，前九次升級各提供一點技能。三項技能各三級：超導電容每級增加 12 能量上限；光流引力每級增加 0.65 公尺收集範圍；城市默契每級增加 3 秒委託時間。升級下次出發生效。結算保留已完成配送的經驗，即使時間用盡也能持續成長。S 評價要求完成三次交付、最多兩次失誤及至少 7,500 分。

## 操作

| 操作 | 功能 |
| --- | --- |
| ← / → | 左右切換一條航道 |
| 空白鍵 | 跳躍；躍動角色在空中可再按一次；選單確認 |
| 按住 ↑ / ↓ | 衝刺／緩行 |
| Esc | 暫停、繼續、返回上一層 |
| 選單方向鍵 | 選取角色、委託、按鈕；空白鍵確認 |
| 手機 | 左側左右換道；右側跳躍、按住衝刺 |

角色命名使用文字輸入；說明、成長與音訊也可用滑鼠或觸控。遊戲固定全螢幕版面，沒有網頁捲軸；只有主動開啟的說明／成長視窗可以內部捲動。觸控按鈕與側邊及底部至少相距 48 px，再加入裝置安全區，按鈕最小 48 px。遊戲文字不接受長按反白，名稱欄位保留正常編輯。暫停、查看說明或離開分頁時，航程與事件時鐘一起停止。

## 本機執行

在專案根目錄執行 `node tools/serve.cjs`，開啟 <http://127.0.0.1:4174/neon_courier/>，或從首頁搜尋「霓光」。靜態 HTML/CSS/JavaScript，不需要建置步驟或外部服務。

`three.min.js` 是專案既有 Three.js 發行檔的本機副本，保留原授權標頭，MIT 授權文字見 `THIRD_PARTY_NOTICES.txt`。造型、招牌、星空與音效皆以程式產生；遊戲載入與遊玩不請求外部資源。音樂和音效在使用者開始操作後由 Web Audio 合成，可從右上角關閉。

角色、技能與最佳紀錄以 `neon_courier_profile_v1` 獨立保存在 localStorage。會驗證不合法的存檔、限制技能點總數；瀏覽器拒絕儲存或不支援音訊時，仍可在本次頁面中遊玩與成長。WebGL 不可用／連線中斷時提供可見的恢復入口。

## 測試

```sh
# 預覽伺服器保持執行；需安裝專案 Playwright 依賴
npm run test:neon-courier
# 或分開執行
node tools/qa-neon-model.cjs
node tools/qa-neon-browser.cjs
# 可只驗證核心流程或六種畫面尺寸
node tools/qa-neon-browser.cjs core
node tools/qa-neon-browser.cjs layout
```

- 模擬測試：108 組固定亂數種子的完整航程，涵蓋三角色、三委託、可通行路線、交付緩衝、碰撞掃描、跳躍、能量、事件、暫停、結算與技能驗證。
- 瀏覽器測試：一場完整航程用真實時間與實際方向鍵完成三次交付，再驗證經驗升級、技能、重載保存；六種畫面尺寸測試開始、觸控、長按釋放、角色換道後可見、暫停、轉向、失敗重試、音訊與受限儲存。另檢查首頁新入口和 WebGL 中斷。
- 截圖與報告輸出到忽略版控的 `.qa/neon-courier/`。手機採瀏覽器模擬，尚未在每款實體手機上驗證效能與手感。玩法與難度可依年輕玩家實際試玩回饋再調整。

模擬核心 `model.js` 不依賴畫面；瀏覽器以固定 90 Hz 步進處理物理，避免高速穿過障礙與不同畫面更新率造成明顯差異。繪圖、音訊與介面分別置於 `world.js`、`audio.js`、`game.js`。

本次驗收已完成 108 組模擬、一場以真實按鍵與即時時鐘跑完的完整委託、角色成長保存，以及六種尺寸的手機／桌機介面檢查。另驗證初始 WebGL 不可用與中斷恢復、受限儲存和音訊；首頁 19 個入口與原有 16 款遊戲的 `tools/verify.cjs` 核心回歸通過。小尺寸橫向結算視窗的按鈕和外框已修正並回歸驗證。
