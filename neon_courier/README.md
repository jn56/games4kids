# 霓光快遞：晴空出發 / NEON COURIER

為 16～20 歲玩家設計的 3D 即時角色扮演與高速配送遊戲。扮演晴空快遞員，在晴空街區、雲端花園、向陽星港之間駕駛浮板，把演出音軌、向陽種子、首映邀請函等包裹送到收件人手中。獨立的新遊戲入口，不修改找媽媽的任何版本。

## 遊戲設計

- **速度與技巧**：角色自動前進，在一整片 23 公尺寬的跑道上自由左右移動、跳躍、衝刺與緩行；靠光環連段提高積分倍率，最高 ×5。較高的光環與越障獎勵鼓勵掌握跳躍時機。
- **分岔與支線**：每趟三處真正分開再匯合的跑道。提前 160 公尺顯示兩條路的玩法；入口相連處仍可左右改選，直到中央護欄真正分開才依角色位置確定支線，正中央預設左路。支線內可自由橫移，匯流處恢復整片相連跑道的活動範圍。分岔前 125 公尺清空一般障礙，保留選路時間。
- **自行操控彎道**：不操作時角色保持直行，一般道路與支線都不會自動帶著角色轉彎；只有實際接觸護欄，牆面才會限制角色位置並產生擦撞回饋。鏡頭平順追蹤實際位置、朝向前方，不提前轉向或因切換支線座標重新置中。分隔牆尖端的碰撞預留距離逐漸增加；支線使用較長的平滑入口、直線挑戰區和匯流段，在現有速度與橫移速度下可以自行完成挑戰。首道衝刺門前的補能帶保留轉向對準時間。
- **四種挑戰**：極速環道增加 6 m/s，衝刺穿三道光門；空中躍台自動彈跳，收集三顆高空星；節奏曲線左右穿四道精準環；磁力花園增加收集範圍，收集六顆光環。完成各支線一次性獎勵 4 秒、積分、能量及 25 XP，磁力花園補滿能量。未完成也能繼續配送，每次出發會改變支線組合。
- **角色扮演**：可自訂代號，選疾風、躍動、共鳴三位快遞員，以及紅、黃、藍皮克敏，共六個可選角色；三種委託各有三位收件人、不同包裹。累積經驗升級，分配永久技能點，建立自己的玩法。
- **即時變化**：順風航道加速、磁力潮汐擴大收集範圍、追光時刻加倍積分。每次委託重新生成路線，每組障礙保留可通行的空間，交付點前後保留 200 公尺障礙緩衝；連續障礙的通行走廊依最高速度限制橫向距離。
- **無血腥、無暴力**：沒有攻擊、武器、敵人、生命值或傷亡。維修設施只是路線挑戰，碰到時短暫減速、減少能量並中斷連段；錯過包裹由接駁機接手，玩家繼續下一站。刺激感來自速度、倒數、連段與路線決策。
- **3D 表現**：平滑追蹤相機、自由橫移、角色傾斜、浮板尾流、立體城市、航道彎曲、遠景霧、藍天白雲、陽光與綠樹。日光使用實際柔和陰影，角色、建築、樹木與設施投影到路面，浮板保留近距離接觸陰影。衝刺時雙噴口產生青白色氮氣噴流與淡霧；碰到同行外送員時雙方輕微彈開，顯示接觸光圈與短暫金色粒子；護欄擦撞保留輕晃，兩者都有柔和音效。物件池與 InstancedMesh 重複使用場景物件。減少動態效果偏好會取消衝刺視角拉伸、尾流粒子和碰撞搖晃，保留較短的穩定噴流與淡出光圈。

紅皮克敏有尖鼻子與葉片，黃皮克敏有大耳朵與花苞，藍皮克敏有小嘴巴與白花；三種均為程式建構的立體角色，分別對應衝刺、二段跳與遠距收集。出發畫面以「快遞員／皮克敏」切換三張角色卡，選取時立即顯示 3D 預覽並保存角色。沿用既有存檔。

遊玩介面僅保留交付方向與距離、倒數、交付數、速度、順位與能量；分岔顯示短選項與進度。一般收集、跳躍不反覆顯示文字，送達與挑戰完成才短暫提示。操作細節放在主動開啟的「說明」視窗。移除沿路紫色裝飾燈柱、星港大型裝飾環及城市文字廣告；真實高障礙改為橘色條紋警示箱，碰撞範圍維持原狀。

## 委託與成長

| 委託 | 長度 | 起始時間 | 特點 |
| --- | --- | --- | --- |
| 晨光補給 | 4.8 km | 180 秒 | 暖身，障礙間隔較大 |
| 屋頂派對 | 5.4 km | 170 秒 | 標準，連段與衝刺的平衡 |
| 星港首映 | 6.0 km | 160 秒 | 進階，路線判斷更密集 |

三條跑道皆為前版兩倍長，維持既有基礎速度與衝刺速度，通常約一至兩分鐘完成；倒數時間配合長度增加。

每次正確穿過交付光門增加 4 秒與 30 點能量。衝刺消耗能量，不衝刺時自動回充；右側衝刺點一下即持續到能量耗盡，放手不取消；回充不會自行再次衝刺，需再點一次。暫停時凍結，繼續後接續剩餘能量。鍵盤按住 ↑ 的模式保留耗盡後回充到 25 點再啟用的保護，避免速度抖動。疾風速度較快、耗能較低；躍動可以二段跳；共鳴的收集範圍較大、回充較快。

一般速度在上一版基礎上再增加 25%：疾風由 52.5 提升至 65.625 m/s（236 km/h），躍動與共鳴由 49.5 提升至 61.875 m/s（223 km/h）。衝刺額外增加 22 m/s；疾風衝刺達 315 km/h，順風與極速支線還能進一步加速。支線物件間距配合新速度調整，空中躍台相隔 108 公尺，預留衝刺與順風時的落地時間。

每 220 XP 升級，前九次升級各提供一點技能。三項技能各三級：超導電容每級增加 12 能量上限；光流引力每級增加 0.65 公尺收集範圍；城市默契每級增加 3 秒委託時間。升級下次出發生效。結算保留已完成配送的經驗，即使時間用盡也能持續成長。S 評價要求完成三次交付、最多兩次失誤及至少 7,500 分。

## 操作

| 操作 | 功能 |
| --- | --- |
| 按住 ← / → | 平順左右移動，放開快速停住 |
| 空白鍵 | 跳躍；躍動角色在空中可再按一次；選單確認 |
| 按住 ↑ / ↓ | 衝刺／緩行 |
| Esc | 暫停、繼續、返回上一層 |
| 選單方向鍵 | 選取角色、委託、按鈕；空白鍵確認 |
| 手機搖桿 | 可任意旋轉，偏左向左、偏右向右；只控制左右，純上下不加減速 |
| 手機右側 | 跳躍；點一下衝刺直到能量耗盡，可與搖桿多指同時操作 |

角色命名使用文字輸入；說明、成長與音訊也可用滑鼠或觸控。遊戲固定全螢幕版面，沒有網頁捲軸；只有主動開啟的說明／成長視窗可以內部捲動。觸控按鈕與側邊及底部至少相距 48 px，再加入裝置安全區，按鈕最小 48 px。遊戲文字不接受長按反白，名稱欄位保留正常編輯。暫停、查看說明或離開分頁時，航程與事件時鐘一起停止。

搖桿中央 18% 為防誤觸區，垂直軸附近另有小幅遲滯，避免手指微晃就反向。依左右半邊控制，斜上斜下不改變前進速度。最高橫移速度由 18 降至 12 m/s，起步採平滑加速，放手或反向快速煞住；全速放手後位移小於 0.3 公尺，不吸附固定位置。不碰搖桿會保持世界座標上的直行，彎道需自行左右操控；碰到護欄才會擦撞，轉向離開牆面時仍保留玩家的輸入。單一道路邊界為中心左右各 9.8 公尺；路口相連時依兩側路面聯集擴大範圍。光環、障礙和交付門皆以實際橫向座標判定。單指捕捉避免第二根手指搶走搖桿；放手、取消觸控、暫停、離開分頁及螢幕轉向均清空輸入。手機網址列伸縮造成的高度變化保留正在操作的搖桿。鍵盤、搖桿與一次啟動的衝刺分別管理，放開搖桿或按鈕不取消已啟動的衝刺。

## 電腦外送員

小嵐、阿澈、米洛、沐沐、星野共五位電腦外送員，同場總共六人。每位都有不同衣服／浮板燈色、近距離小色點、初始位置與配速。會自主選分岔、左右避障、使用跳台、管理衝刺能量並穿門配送；左下顯示即時航程順位。

開場前 240 公尺為直路，主跑道改為左右各最多 4 公尺的緩彎，避免角色直行時一開場就靠上左護欄。分岔仍需玩家選路與轉向。角色放手後不自動置中或隨彎道轉向；前後對齊的外送員碰撞僅減速、顯示光圈，不固定往左推。真正的側面碰撞仍依接觸方向輕微分開，護欄接觸才限制角色位置。

外送員使用同一條路線，但各自擁有獨立的物理、能量、光環、配送和結算狀態，不會消耗玩家的光環或改寫玩家存檔。倒數與暫停期間全員停止，重新接單時重建五位外送員。輕碰同行者時雙方各向外分開最多 0.24 公尺並減速 5%；護欄擦撞短暫減速 3%，不扣能量、不打斷連段，不計為設施失誤；接觸回饋有 0.65 秒間隔保護。跳過外送員、處於另一條分開支線時不誤判接觸。

## 本機執行

在專案根目錄執行 `node tools/serve.cjs`，開啟 <http://127.0.0.1:4174/neon_courier/>，或從首頁搜尋「霓光」。靜態 HTML/CSS/JavaScript，不需要建置步驟或外部服務。

`three.min.js` 是專案既有 Three.js 發行檔的本機副本，保留原授權標頭，MIT 授權文字見 `THIRD_PARTY_NOTICES.txt`。造型、招牌、天空與音效皆以程式產生；遊戲載入與遊玩不請求外部資源。音樂和音效在使用者開始操作後由 Web Audio 合成，可從右上角關閉。

角色、技能與最佳紀錄以 `neon_courier_profile_v1` 獨立保存在 localStorage。會驗證不合法的存檔、限制技能點總數；瀏覽器拒絕儲存或不支援音訊時，仍可在本次頁面中遊玩與成長。WebGL 不可用／連線中斷時提供可見的恢復入口。

## 測試

```sh
# 預覽伺服器保持執行；需安裝專案 Playwright 依賴
npm run test:neon-courier
# 或分開執行
node tools/qa-neon-model.cjs
node tools/qa-neon-browser.cjs
node tools/qa-neon-handling.cjs
node tools/qa-neon-fork-camera.cjs
node tools/qa-neon-daylight.cjs
node tools/qa-neon-manual-steering.cjs
# 可只驗證核心流程或六種畫面尺寸
node tools/qa-neon-browser.cjs core
node tools/qa-neon-browser.cjs layout
```

- 模擬測試：576 組固定亂數種子的完整航程，涵蓋六角色、三委託、所有八種選路組合與四種挑戰，確認三次配送與挑戰均有零設施失誤的完成路徑。另驗證分岔幾何連續、未選支線不碰撞／計分、自動跳台、高空星高度、衝刺門、一次性獎勵、暫停與原有成長規則。
- 電腦外送員測試：45 趟獨立航程、135 次配送，驗證自主選路、跳台、衝刺、移動邊界、暫停，以及與玩家拾取物／存檔隔離。
- 控制與接觸測試：相連路口左右改選、選路與匯流座標連續、中央護欄碰撞、放手煞停／快速反向、外送員接觸／高度與分支隔離、回饋間隔與暫停凍結，以及精確的 25% 基礎加速。
- 分岔鏡頭回歸：同一實際位置切換支線座標時，鏡頭位置、視線及角色朝向不改變；桌面、手機直向／橫向以固定步進逐幀檢查左右分岔與靠近中央的入口，涵蓋完整分開／匯流過程，限制單幀平移及轉向幅度，並輸出過渡截圖與數據。
- 手動轉向回歸：三種角色、三處分岔及左右支線逐步檢查，未操作時自由空間內世界橫向位置不變，任何橫向位移都必須發生在實際護欄邊界。桌面與手機直向／橫向瀏覽器驗證不操作直行、原生搖桿放手停止、真正擦牆才出現光圈，以及操控離開牆面仍能正常移動。
- 手機控制回歸：直向及橫向原生指標操作穿越相連路口、垂直軸防抖、網址列高度變化保留搖桿、轉向清空輸入、實際護欄接觸光圈、一次衝刺噴氣／暫停／耗盡停止、粒子幾何重用與減少動態效果偏好。
- 瀏覽器測試：一場完整航程用真實時間與實際方向鍵完成三次交付與支線挑戰，再驗證經驗升級、技能、重載保存；六種畫面尺寸測試搖桿全角度只控制左右、防誤觸、一次衝刺／耗盡停止／再次啟動、自由橫移與放手停留、反向、原生多指操作／取消、暫停、轉向、失敗重試、音訊與受限儲存。跑道兩側邊界及分岔相機與 HUD 的尺寸檢查使用指定航程位置，與完整即時航程分開驗證。另檢查首頁入口和 WebGL 中斷。
- 白天與角色回歸：五種畫面尺寸驗證六個角色的實際 3D 模型切換、保存與重載，陽光／雲層／陰影、雙倍路程，以及同行雙方的輕微分離、接觸光圈、粒子、暫停凍結與頁面不溢出。
- 截圖與報告輸出到忽略版控的 `.qa/neon-courier/`。手機採瀏覽器模擬，尚未在每款實體手機上驗證效能與手感。玩法與難度可依年輕玩家實際試玩回饋再調整。

模擬核心 `model.js` 不依賴畫面；瀏覽器以固定 90 Hz 步進處理物理，避免高速穿過障礙與不同畫面更新率造成明顯差異。繪圖、音訊、觸控搖桿與介面分別置於 `world.js`、`audio.js`、`controls.js`、`game.js`。

首頁保留 19 個遊戲入口與所有既有遊戲；可用 `node tools/verify.cjs` 執行首頁和原有 16 款遊戲的核心回歸檢查。
