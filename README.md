# 遊戲小花園

給孩子的網頁遊戲集合。首頁提供分類、搜尋與個人最佳紀錄；16 個遊戲採用一屏遊玩的版面，遊戲區填滿工具列以外的空間，2D 畫面依原比例放到最大，3D 畫面隨視窗延展。手機的觸控操作與遊戲保持在同一屏，無須捲動頁面。`find_mom_3d` 保留原有內容，沒有載入新的共用介面。

鍵盤只使用方向鍵、空白鍵、A／S／D 與 Esc。空白鍵可以開始、過關繼續及重玩；Esc 開啟暫停選單，用方向鍵與空白鍵調整音訊或返回首頁。各遊戲的動作提示顯示在下方或選單中，首頁也能用方向鍵選遊戲、空白鍵進入。

11 個平面遊戲與小地圖會依顯示尺寸和螢幕像素密度重新繪製，最多採用 3 倍像素密度；5 個立體遊戲最多採用 2 倍，兼顧清晰度與繪圖負擔。旋轉裝置、調整視窗或切換螢幕時會更新解析度，遊戲的邏輯尺寸、速度與操作座標維持原樣。

## 本機預覽

安裝 Node.js 後，在專案資料夾執行：

```sh
npm start
```

開啟 <http://127.0.0.1:4174/>。網站使用靜態 HTML、CSS、JavaScript，遊戲音樂與音效由 Web Audio 即時合成，首次點擊或觸控後啟用。音樂與音效可以各自關閉；瀏覽器禁止儲存或不支援音訊時仍可玩遊戲。

## 驗證

保留預覽伺服器執行，在另一個終端機執行：

```sh
npm install
npm test
```

測試使用 Windows 上的 Microsoft Edge，結果與畫面存入忽略版控的 `.qa/` 資料夾。

- `tools/verify.cjs`：首頁入口、核心操作、計分、勝敗、重玩、暫停、受限儲存，以及已修復問題的回歸測試。較長的關卡流程以設定遊戲狀態重現，並非每一關都靠人工走完。
- `tools/input-audio.cjs`：16 個遊戲在 3 倍像素密度下的手機觸控、音訊實際啟動、音樂／音效獨立開關與設定保存。
- `tools/audit.cjs`：16 個遊戲在 1440×900、390×844、320×568、844×390 四種尺寸的完整畫面、最大可用尺寸、不需捲動、按鈕可見、鍵盤開始與選單、資源載入與程式錯誤檢查，並測試遊戲進行中的視窗尺寸切換。
- `tools/display.cjs`：16 個遊戲在四種尺寸下的高像素密度畫布、暫停時轉向重繪、同尺寸切換像素密度、骰子與紀錄左右分欄、完整骰盤視角、小地圖避讓資訊欄、手機轉向後的翻牌／節拍操作，以及兩款追逐遊戲的相機視角檢查。

手機測試使用瀏覽器模擬；不同實體裝置的觸控手感仍可再依使用回饋調整。
