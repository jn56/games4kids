# 小米找媽媽：回家的四盞燈

## 設計目標

給 7～12 歲孩子的溫柔 3D 探索遊戲。孩子扮演小女孩「小米」，在童話森林裡與媽媽走散。每關都有願意主動幫忙的動物朋友。核心不是逞強，而是「害怕也可以慢慢來；觀察、表達與求助都是勇敢」。

情緒順序：**失去 → 希望 → 找回 → 再失去 → 勇敢 → 真正重逢**。

視覺採用有立體感的繪本花園：柔和夕陽、圓潤人物、明確路徑、精緻小景與奶油色介面。只有移動與互動兩種基本操作。文字短句、手動翻頁，沒有閱讀時間限制。顏色線索一定搭配圖形、名稱及編號。

## 第一關完整流程（已實作）

1. **封面與開場**：繪本式標題覆蓋在實際 3D 花田上，按「陪小米出發」。先以短對話和動畫呈現野餐、蝴蝶與霧中走散，再開始尋找髮帶；可暫停、略過。
2. **找熟悉的東西**：入口小徑有媽媽的紅髮帶；任務、地面引導與目標標記帶玩家上手。靠近按 E／空白鍵／觸控按鈕調查，得到第一個真實線索。
3. **勇敢開口求助**：穿藍背心的兔子阿蹦立即告訴小米媽媽也在找她。NPC 不以完成跑腿交換重要安全訊息，而是邀請合作點亮引路燈。
4. **風車郵局**：到綠色郵箱旁找刺蝟栗栗，幫牠旋轉九格風管，接通送信的路。取回媽媽的信，風車重新轉動、光花醒來。
5. **三座花圃與線索手帳**：風車旁的「太陽花」、池塘旁的「愛心花」、老樹下的「星星花」，可任意順序收集。每朵都有不同造型、名稱及一條排列線索。手帳能重讀媽媽的信與找到的線索。
6. **動腦點亮希望**：把三朵花和髮帶放進燈的四個位置，讓三條相對位置線索同時成立。答錯保留全部回憶，並回饋哪些條件符合。解對後燈亮起，沿路出現金色光點。
7. **出發到下一段故事前**：栗栗寄出回信，阿蹦陪小米走到花拱門，讀完媽媽的遠方呼喚與小米回應。顯示第一關完成、獲得希望之光及回顧，可選擇重玩第一關或前往第二關。

## 操作、節奏與保護

- 桌面：WASD／方向鍵移動，E／空白鍵互動，Esc 暫停。按鈕同樣可點擊。
- 手機／平板：左下方向搖桿，右下互動；對話期間停用走路。
- 固定角度、柔和追蹤的攝影機，不必操作視角。移動方向與螢幕方向一致。
- 每次只強調一個下一步。提供「給我提示」，指向最近的未完成目標。
- 無死亡或血量。第二關即時挑戰使用風勢倒數與安全存點，失誤只退回最近存點。花田有實體邊界，樹幹、池塘及布景有碰撞。
- 支援暫停、聲音切換、減少動態偏好、失焦清除按鍵、頁面隱藏暫停。
- 每次謎題操作及任務節點都保存進度，包含目前關卡；重新開啟可繼續。無儲存權限時，當次頁面仍能遊玩、換關及重玩。
- 程式繪製場景與角色，使用本地 Three.js，不需要外部模型、字型或網路資源。

## 第二關完整流程：風鈴森林（已實作）

第一關加強版完成後，可以在結算畫面直接前往第二關。第二關採用獨立的青綠森林、發光蘑菇、三座風鈴、藤蔓門、可升降安全橋和對岸休息亭，不複製花田。

1. 小米進入森林，遇見貓頭鷹「咕咕」。咕咕告訴她媽媽就在橋邊，藤蔓門需要熟悉的旋律才能打開。
2. 合奏台提供三段旋律挑戰：3 音正序、4 音正序、5 音倒序。每個音都有顏色、圖案、名稱與亮起提示，靜音也能完成。可無限重播；每段答錯只重做當段，已通過段落保留。連錯三次保留圖示樂譜，玩家也可主動請求逐步提示。
3. 三段完成後闖過「疾風小徑」：左右換跑道，閃過六波陣風，中途保存一次。通過後藤蔓門完全開啟。玩家走到媽媽身邊互動，演出靠近、擁抱及對話，落實「找回」。
4. 媽媽先過橋確認通往山丘的道路，小米留在咕咕身邊等候。媽媽完整走到對岸後才起霧，安全橋收起；鏡頭同時呈現兩人、河與橋。這是「再失去」，不呈現墜落或受傷。
5. 媽媽立即清楚說她已在對岸休息亭，很安全，請小米和咕咕走河谷步道。小米向咕咕再次求助，挑戰「風停快跑」：在越來越短的風停時間內穿越三段小路，各避風亭保存進度，再帶著「記憶之光」走向東邊出口。
6. 第二章結算停在第三關入口，第三、四關仍不實作。可重玩第二章，或從第一章重新開始。

第二關獨立保存已完成旋律、目前正確前綴、提示次數、重逢／再分開／問路狀態。關卡切換時清除舊目標、人物標籤與互動，不重複建立場景。過橋演出可暫停；中途重開會從已保存的安全節點恢復。驗收涵蓋第一關銜接、不能跳關、旋律正逆序、重播／暫停／錯誤保留、真正重逢、橋只在媽媽安全到岸後收起、手機操作及第二關完整通關。

## 第一關難度設計：觀察與推理

- 新增刺蝟「栗栗」：風車郵差，位於風車旁的綠色郵箱。媽媽留下的信被卡在停轉的風郵管裡。栗栗因為著急把風管轉亂；小米和牠學會把大問題拆成一格一格。
- 第一段謎題為 3×3 風管。每格點一下順時針轉 90 度，讓左上入口連到右下出口，且九格都必須通風。要觀察管口是否相對，不能只把全部轉成同一個方向。
- 試送風後只標出風走到哪裡、停在哪裡，不扣分、不清空旋轉。完成後演出媽媽的信與風車重新運轉，光花才開放採集。
- 第二段謎題為四個物件的空間排列：三朵光花＋媽媽的紅髮帶。每朵花保存一條線索到手帳，孩子需要合併「相鄰」「隔一格」「左右先後」三個條件。唯一解是：紅髮帶、太陽花、愛心花、星星花；初始供選物件順序刻意不是答案。
- 引路燈會逐條核對條件，答錯保留排列與全部花朵。可以點空格放入、點已放物件取回，不要求拖放或搶時間。
- 提示依玩家請求逐步增加。風管提示先講管口規則，再指出斷點，最後可示範轉對一格；排列提示先提醒先處理相鄰條件，再協助排除，最後說明完整推理。
- 新流程：髮帶 → 阿蹦 → 栗栗 → 修風管與媽媽的信 → 花朵及三條線索 → 推理點燈 → 阿蹦陪伴、栗栗送信 → 拱門結尾。
- 設計遊玩時間調整為約 10～15 分鐘；仍待兒童實玩校準。難度來自連通性與約束推理，沒有增加找物數量或處罰。
- 舊版存檔保留髮帶、已收集花朵與位置，但新增兩段謎題需要完成；不讓舊版已點燈的標記跳過新內容。新存檔也記住旋轉、排列與已使用提示。

### 加強版驗收

- 栗栗、風車、郵箱都可見，首次／重訪／完成後有不同對話。
- 風管錯誤、部分相通、完整連通皆正確判定；沒有風管解答不能點燈。
- 排列 24 種置換中只有一組通過；不完整與重複物件不可送出或解鎖。
- 花朵線索可隨時重讀；答錯、收起謎題、暫停、刷新都保留操作。
- 手機直向／橫向可以看完整謎題並操作；鍵盤可完成兩個謎題。

- 能完成：開場 → 髮帶 → 阿蹦 → 栗栗與九格風管 → 三朵花與線索 → 引路燈排列 → 拱門 → 完成畫面。
- 重複 NPC 對話不重生花朵；重複互動不增加數量；未完成任務不能直接通關。

- 重玩、刷新續玩都保留正確狀態，第一章完成後可主動前往第二關。

## 第二關驗收

- 第一關結算可進入獨立森林，舊場景與標籤完全隱藏。
- 咕咕介紹、筆記、三段旋律、打開藤蔓門、媽媽擁抱、過橋、再次問路、出口結算都可實際完成。
- 示範期間不可搶答；可暫停、重播、收起；正確前綴、已過段落與提示狀態可保存。
- 第三段拒絕原順序、接受倒序；錯三次保留原樂譜，再提供下一音與完整作答順序。
- 演出期間小米留在安全岸上；橋只在媽媽安全到對岸後收起。刷新可從重逢後的安全節點重播。
- 未完成旋律與疾風挑戰不能穿越藤蔓門；未重逢、未問路或未通過三座避風亭不能結算。
- 咕咕問路後跟隨小米走向出口；第二章重玩只重置森林，保留第一章紀錄。
- 桌面及手機直向／橫向可操作旋律；手機過橋鏡頭同時容納小米與媽媽。
- 版本 2 存檔可接第二章；損壞進度不跳過必要節點；儲存不可用仍可在本頁換關與重玩。
