# 小米找媽媽 · 回家的四盞燈

給約 12 歲玩家的 3D 推理與即時冒險。四關串接到母女一起回家的結局；第五關僅保留設定，尚未製作。

## 開啟與操作

直接開啟 index.html，或在 games4kids 目錄執行：

```powershell
node find_mom_3d/scratch/serve.cjs
```

瀏覽 http://127.0.0.1:4173/find_mom_3d/ 。WASD／方向鍵移動，E／空白鍵互動，Esc 暫停。手機提供搖桿與各遊戲專用按鈕。封面、暫停能選關；選關會重新開始該關並取代目前存檔。遊戲內從步道出入口往返則保留進度。

## 大地圖與小地圖

四關探索邊界的寬、深各擴大至原本 2.5 倍，加入環形步道、果園／茶席、畫台、營地等休憩點；碰撞網格驗證四關可行走面積都超過原本四倍。角色與主線挑戰維持正常大小，鏡頭跟隨小米探索外圍。

右上角小地圖以紅色箭頭標示小米、金色菱形標示目前目標，藍色圓點標示朋友；空心圓為聊天角色，圓形地區圖示是出入口。下方箭頭可切換前／後一關入口的路線指引，左上角 ◎ 回到主線目標。地圖上方按鈕可以收合，對話、解謎與即時挑戰期間暫時收起。

四關以花田北口 ↔ 森林南口、森林東口 ↔ 河谷西口、河谷北口 ↔ 山丘南口相連；成對入口延續樹木、蘆葦或星燈景色。走過路標，或靠近後按互動，即可切換地圖。完成目前關卡後開通下一關，前面的地區可以自由回訪，解謎、物品和支線選擇都保留。河谷通關後出現回程木橋，直接從第四關開始也能沿橋回到南岸。首次前進才播放介紹；結算可選「繼續探索」。

探索介面只常駐短目標、進度條和圖示按鈕，線索留在筆記中；靠近角色才顯示名字。每關五位聊天朋友會在自己的工作區走動、拿工具工作，園丁澆水、讀書人翻書、木工敲工具等；小米靠近時停下交談，暫停時一起停止。主線朋友也有短程活動，跟隨和劇情演出優先。

每關有五位聊天 NPC。原有三位朋友藏著可選支線；南側環形步道的兩位朋友則透過生活小故事聊親情，皆不影響主線通關：

| 關卡 | 聊天朋友 |
| --- | --- |
| 黃昏花田 | 桃桃（園丁）、慢慢（畫家）、啾啾（歌手）、穗穗（麵包師）、綿綿（縫補師） |
| 風鈴森林 | 墨墨（讀書人）、苔苔（觀察員）、露露（晨露收藏家）、鈴鈴（風鈴工匠）、榛榛（送信人） |
| 月光河谷 | 豆豆（廚師）、石石（記錄員）、帆帆（紙船設計師）、橋橋（木工）、暖暖（煮粥人） |
| 星光山丘 | 眠眠（茶師）、圓圓（星空畫家）、晚晚（夜班信差）、映映（燈籠師）、絮絮（織毯人） |

親情對話依序談日常關心與不必完美、傾聽與表達害怕、道歉後的行動與分擔、保護彼此與不同樣貌的家庭。每段以短句分頁，小米也會回應自己的想法；可隨時再聊，不影響主線。

可選支線分別從桃桃、墨墨、豆豆、眠眠開始：找回野餐畫的主人、補完晚安歌、替紙船送平安消息、為晚歸的人畫星燈。依提示拜訪朋友並回報，就能收藏一份旅途回憶；完成後再回訪最後一位朋友，還藏著彩蛋。筆記會記下下一站與收藏，進度可存檔接續。

南側兩位朋友另外有四段選擇故事：穗穗的生日麵包、鈴鈴的空白心事卡、橋橋修好的小凳子、映映的回家燈。每段有兩種回應與後續；完成後回訪兩位朋友，各有一個彩蛋，共新增八個。讀完回應才保存選擇，支線不改動主線里程碑。

## 自由互動與生活小角落

每關另外增加四位會活動的朋友及 14 個互動物品，分散在球場、送貨站、花圃與休息點；共新增 16 位 NPC、56 個物品。花田和河谷的北側也有朋友，河谷北岸在渡河後可探索。小地圖上的棕色空心圓是新朋友，身邊的小方點是物品；靠近會出現金色互動圈與短提示。

| 操作 | 場景反應 |
| --- | --- |
| 靠近後按 E／互動 | 踢球、推箱子、敲鼓、轉風車、搖風鈴、澆花或坐下。球和箱子有碰撞、摩擦與反彈，走路也能推動。 |
| 和球友互動 | 球友傳球給小米；射進球門會歡呼、記分並重新發球。 |
| 借滑板車 | 移動加快，靠近人群自動減速。可以載著包裹騎車，按 E／互動下車，包裹仍拿在手上。 |
| 拿包裹 | 緞帶顏色對應收件人的圍巾，小地圖與光點指向收件人；交到正確朋友手上才完成。 |
| 按 Q／放下 | 把包裹放到身邊的空地。未拿包裹時，Q 也可下車或起身；坐著時推動搖桿即可站起。 |
| 接近 NPC 或從旁經過 | 朋友會招手、側身讓路；敲鼓與風鈴會引來附近朋友回應。 |

送達的包裹、開花狀態與進球數各關分開保存，不改動主線或原有支線。包裹能跟著玩家完成同一張地圖的主線挑戰；過河前仍先引導修橋、渡河，回程則沿木橋。切換地圖或重新載入時，未送達的包裹、借車和散物歸位，已完成紀錄保留。新 NPC 的短台詞也收進首頁配音室。互動沿用靜音、暫停和減少動態設定。

## 角色配音室

首頁按「角色配音室」，按角色、關卡或台詞搜尋，一句句錄音、重錄、試聽。勾選「只看未錄」可繼續補錄。劇情、NPC、選擇分支與動畫旁白共用台詞目錄；媽媽不同情境的聲音歸在同一角色。

錄音只保存在目前瀏覽器的 IndexedDB，不上傳。可匯出 JSON 備份，再在另一台裝置匯入；匯入保留已有配音，只補上缺少的句子。清除網站資料或使用無痕模式可能失去錄音，請先匯出。錄音與冒險存檔分開，選關、重玩都保留配音。

按錄音才請求麥克風權限，每句最多 30 秒。關閉配音室或離開分頁會取消本次錄音並關閉麥克風；重錄儲存失敗仍保留舊錄音。建議使用 HTTPS 網站或上面的 localhost 預覽；瀏覽器的麥克風權限與安全環境規則見 [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。遊戲會使用錄好的台詞，翻頁、暫停、靜音會停止播放；沒有錄音的句子照常顯示文字。

修改劇本後執行 `node find_mom_3d/scratch/build-voice-catalog.cjs` 更新台詞目錄；`--check` 可驗證是否同步。音檔以角色與台詞文字識別，新增或重排台詞不會錯配原有錄音。

## 四關玩法

| 關卡 | 推理與操作 | 新的挑戰量 |
| --- | --- | --- |
| 黃昏花田 | 4×4 風管；同號齒輪反向連動。合併三張線索卡，排列花朵、髮帶、歌譜與船票。 | 16 格連動風管；6 件物品、720 種排列中只有一個解。 |
| 風鈴森林 | 六音正序、七音首音移到最後、八音倒序。疾風逐波加速，反向波有橘色大字及按鈕方向提示。石頭隨水持續往下漂，玩家須往前連跳九排；避開毒香菇和炸彈，被帶出畫面就失敗。 | 21 音、18 波疾風、9 顆落腳石。 |
| 月光河谷 | 中央大字顯示心算／數列題目，瞄準下方對應數字敲鉚釘。木筏掌舵穿過左右移動的入口，E 切換煞船；煞船能量用完需回充。 | 9 枚鉚釘、12 道移動水門。 |
| 星光山丘 | 左右追蹤星光充能，金色曝光窗時按 E 拍下。護送媽媽躲過灰爪連續衝刺；後段有佯攻與移動安全道。 | 每燈 3 次曝光，共 9 次；9 波追擊後拉下木柵門保護媽媽。 |

挑戰時間靠增加有變化的操作與判斷延長；移動速度提高，旋律示範間隔縮短。實際遊玩分鐘數取決於推理、重試與閱讀速度，尚待約 12 歲玩家實測，不以拉長動畫或等待湊時數。

## 故事與旅途物品

情緒依序為失去 → 希望 → 找回 → 再失去 → 勇敢 → 真正重逢。

第一關：兔子阿蹦、刺蝟栗栗協助小米尋找媽媽。修好風管得到媽媽的歌譜與月光船票；點亮引路燈得到星光鏡片。歌譜用於第二關旋律提示，船票用於第三關登筏與水路提示，鏡片用於第四關望遠鏡。物品與線索可在手帳重讀，直接選後面的關卡會備齊用品。

第二關：貓頭鷹咕咕引路，小米短暫找到媽媽。灰爪企圖抓走小米，媽媽為保護女兒與他扭打，兩人一起落河、被沖往下游。媽媽落水後喊「小米，快逃啊！」，以加大字幕呈現；小米留在岸上，向咕咕求助。

扭打過程中，媽媽與灰爪會直接交鋒對話。玩家先按住右方向鍵／D（或畫面按鈕）退到咕咕身邊，再按三次 E／吹哨按鈕向下游求援。操作時劇情時間暫停，媽媽繼續擋住灰爪；完成後才接續落河情節。中途離開、重讀會從這段衝突開始重演。

第三關：河狸木木接應媽媽上岸；灰爪也被巡林員救起照顧。小米與木木合作修橋、渡河，前往山丘。

第四關：松鼠星星接應。灰爪離開休息站、再次追來，小米擋在媽媽前面。玩家護送兩人躲過追擊，小米最後放下木柵門擋住灰爪。母女擁抱，媽媽跟隨小米一起回家。

## 進度與協助

版本 6 保存每枚鉚釘、水門、曝光及追擊波次。失誤只重試當前小段；暫停會停止挑戰，切換關卡會清理動態場景。第 1～5 版存檔保留已驗證完成的里程碑，未完成的舊風管／排列改用新版題目，舊旋律尚未完成的輸入清空。重玩目前關卡可體驗完整新難度。

即時遊戲累計失誤 6 次後才放寬容錯；觀星需嘗試 30 秒才增加一級協助。推理與歌譜提示仍可主動請求。失誤不演出死亡或受傷，第四關由小米護住媽媽退回安全點。支援減少動態、靜音、鍵盤與觸控。灰爪登場和追擊時切換緊張配樂，危機解除後恢復原配樂。

## 驗證

`scratch/qa-living-world.cjs` 驗證六個方向的實際出入口、步行連通性、關卡進度與支線保存、首次介紹、回程木橋、重逢後媽媽的讀檔位置，以及 20 位 NPC 的行走碰撞、工作、交談停步和暫停。另檢查桌機、手機直橫向與 320px 畫面的精簡介面。

`scratch/qa-sandbox.cjs` 驗證新增 NPC／物品可達性、配音涵蓋、實際踢球與推箱子、送錯人／放下／送達、開花保存、騎車速度與碰撞、NPC 讓路、暫停、切圖及手機觸控配送操作。

`scratch/qa-story-studio.cjs` 驗證新支線兩種結局、八個彩蛋、存檔、桌機／手機求援操作，以及使用模擬麥克風的實際 MediaRecorder 錄音、試聽、匯入匯出和遊戲播放。`scratch/qa-voice-edge.cjs` 驗證手機直橫向排版、儲存失敗、格式錯誤不部分匯入、錄音上限、動畫配音不重複觸發及無法儲存時的提示。測試不使用真實麥克風，也不提交測試截圖或玩家錄音。

scratch/qa-river-reaction.cjs 驗證全體石頭與角色漂流、固定鏡頭、實際出畫面失敗、毒香菇與炸彈判定，以及桌機／手機直橫向的九連跳、暫停和讀檔。scratch/qa-side-stories.cjs 驗證四條支線的順序、讀完才存檔、回訪彩蛋、筆記，以及主線進度不受影響。

旋律完成會保留全部音符，按「下一段」或「完成合奏」再繼續；木筏、拍星光的成功與失誤提示至少保留 1.4 秒。

新版驗收腳本：scratch/qa-age12.cjs（四關主要挑戰、唯一解及舊檔升級）；scratch/qa-age12-mobile.cjs（觸控、直橫向布局及中途存點）。scratch/qa-fixes.cjs 另外逐音核對顯示數量，檢查單次點擊跳躍、煞船按鈕、提示保留與配樂切換。scratch/qa-river-update.cjs 驗證九顆跳石、救援與存點、媽媽台詞及五種尺寸的中央修橋題；scratch/qa-gust-directions.cjs 驗證十八波加速與反向提示。需要 Playwright 與 Edge。scratch/qa-exploration.cjs 檢查四關面積、NPC 可達性、對話不改進度、外圍存點與小地圖布局。詳細設計見 DESIGN.md。
