# 小米找媽媽 · 回家的四盞燈

給 7～12 歲孩子的 3D 繪本解謎冒險。**四關已完整串接到與媽媽一起回家的結局**。玩法與故事設計請看 [DESIGN.md](DESIGN.md)。

## 開啟遊戲

直接用支援 WebGL 的瀏覽器開啟 `index.html` 即可遊玩，不需安裝套件或連上網路。若想用本機網址預覽，在 `games4kids` 目錄執行：

```powershell
node find_mom_3d/scratch/serve.cjs
```

接著開啟 `http://127.0.0.1:4173/find_mom_3d/`。預覽服務只接受本機連線。每關完成後，按「前往」繼續下一關。

## 怎麼玩

- WASD 或方向鍵移動；靠近目標按 E／空白鍵，或點畫面上的互動提示。
- 手機與平板使用左下搖桿、右下互動按鈕；閱讀對話時點「繼續」。
- Esc 或右上暫停鈕休息；音符按鈕開關聲音（預設靜音）。
- 左上「給我提示」說明下一個目標，腳邊光點提供方向。
- 謎題可用滑鼠／觸控點選，或 Tab 選按鈕、Enter／空白鍵操作。風鈴也能按數字 1、2、3。
- 自動保存關卡、謎題操作與劇情進度。關閉再開可繼續；暫停選單可重玩目前關卡，封面可從第一章重新開始。
- **選擇關卡**：封面的「選擇關卡」，以及暫停／通關畫面的「選擇其他關卡」，都能直接進入任一關，不必先通過前面的關卡。選關會從該關開頭開始並取代目前存檔；取消則保留原本進度。之後可照常續玩、重玩或前往下一關，跳過的關卡不會標為通關。

## 第一關：黃昏花田

第一關也準備後三關的旅途物品，取得後可在手帳重讀用途：

- **媽媽的歌譜**：修好風管、收到信時取得。預告森林第三段「回聲要倒著敲」；第二關的「翻媽媽的歌譜」可查看圖示旋律與逐步提示。
- **月光船票**：同封信裡取得，印著「從兩盞浮燈中央穿過」的線索。第三關木木辨認船票，搭木筏前會核對船票並重述操作提示。
- **星光鏡片**：點亮引路燈後，從燈下的小抽屜取得。第四關交給星星、裝上望遠鏡，才能開始追蹤星光。

物品不會消耗，依已保存的風管／引路燈進度持續攜帶。舊存檔自動具備已取得節點的物品；直接選第二至第四關則備齊旅途物品，不會因此把略過的關卡標為通關。

野餐前情 → 調查紅髮帶 → 找兔子阿蹦 → 找刺蝟栗栗 → 修好風管、讀媽媽的信 → 探索三朵光花的線索 → 解開引路燈 → 與阿蹦走到花拱門。

- **風車郵局**：點擊旋轉九格風管，使風從左上格的左邊進入、走過全部九格、從右下格右邊離開。試送風會指出停在哪裡，答錯不清空操作。
- **引路燈**：合併三條「相鄰、隔一格、左右先後」線索，安排三朵光花與紅髮帶的位置。先選回憶再點空格；點已放入的回憶可取回。
- **信與線索手帳**：隨時重讀媽媽的信與找到的線索。提示逐級增加，可請求示範或完整推理。

## 第二關：風鈴森林

問貓頭鷹咕咕 → 風鈴合奏台 → 完成三段旋律 → 疾風小徑 → 與媽媽擁抱 → 媽媽安全到對岸後起霧、橋收起 → 向咕咕問路 → 風停快跑 → 一起走向月光河谷出口。

- **三段旋律**：3 音正序、4 音正序、5 音倒序。先播放示範，再作答；每個音有不同形狀、顏色、名稱與亮起提示，靜音也能完成。
- **記憶與順序推理**：第三段要反過來敲。答錯只重試當段，已完成段落保留。可以無限重播；連錯三次留下圖示樂譜，也可主動請求下一音或完整作答順序。
- **真正重逢與再次分開**：在 3D 場景中實際演出擁抱、過橋、起霧、橋收起。媽媽先安全到岸才收橋，小米留在咕咕身邊；過場可暫停，途中刷新會重播安全節點。
- 完成後獲得「記憶之光」，可重玩第二章，並保留第一章完成紀錄。可直接接著前往第三關。

沒有攻擊或死亡。即時挑戰需掌握時機，失誤會退回最近安全存點。儲存不可用時，這次開著的頁面仍可繼續遊玩、換關和重玩，但關閉頁面後無法保留進度。舊版收花存檔保留花朵但需解新增謎題；已完成加強版第一關的存檔可直接接第二關。

## 第三關：月光河谷

找河狸木木 → 合作修橋 → 走過橋到小島 → 搭木筏穿過四道水路 → 前往星光山丘，獲得「勇氣之光」。

- **時機修橋**：指針走進金色區域時，按 E／空白鍵或「敲一下」。三段逐漸加快、縮小區域；連續失手後木木幫忙扶穩。每段完成自動保存。
- **木筏引路**：按住 A／D、左右鍵或螢幕箭頭，在漂流中穿過兩盞金色浮燈。四道水路方向交替、流速漸快；碰到障礙只重試當道，失手三次會放慢水流、放寬通道。

## 第四關：星光山丘

找松鼠星星 → 自選順序點亮三座燈 → 點亮山頂的陪伴之光 → 媽媽循光走來、擁抱 → 陪媽媽走到小屋 → 演出一起進門，四盞燈完整結局。

- **追蹤星光**：按住左右鍵／螢幕箭頭控制光圈，持續對準移動的星星。三盞燈逐漸提高追蹤難度；暫時偏離只緩慢減少進度，星星會逐步協助穩定望遠鏡。
- 每盞燈、重逢及通關都保存；重逢動畫中重新整理會重播安全節點。媽媽重逢後會在場景裡跟著小米走，直到兩人一起回家。
- 兩關挑戰都可暫停、離開再試；靜音可完成。閱讀對話無時間限制，大字短頁維持不變。

- `js/journey-worlds.js`：河谷、山丘、河狸與松鼠模型。
- `js/journey-story.js`：第三、四關故事、重逢與一起回家演出。
- `js/journey-trials.js`：修橋、木筏、星光追蹤與漸進協助。
- `game.js`：初始化、關卡切換、暫停、介面與主迴圈。
- `js/story.js`：第一關故事、版本 5 存檔、四關進度驗證及舊檔升級。
- `js/challenges.js`：風管連通、四物件排列、分層提示與線索手帳。
- `js/forest-story.js`：第二關故事、重逢與安全過橋演出。
- `js/song.js`：三段旋律、正逆序判定、圖示樂譜與提示。
- `js/level.js`、`js/forest.js`、`js/art.js`：前兩關地景、碰撞、互動物件及共享模型。
- `js/player.js`、`js/npc.js`：小米、阿蹦、栗栗、咕咕、媽媽造型與動作。
- `js/input.js`、`js/interaction.js`、`js/dialogue.js`、`js/camera.js`：操作、互動、對話、鏡頭。
- `js/audio.js`：瀏覽器即時合成音樂與提示音。
- 舊稿的 `js/puzzle.js`、`js/beast.js` 保留但不載入，不參與本版遊戲。

使用本地 Three.js r128、HTML、CSS、原生 JavaScript，沒有框架、建置或遠端資源依賴。支援系統「減少動態」偏好。

## 驗證

測試使用 Playwright 與 Microsoft Edge，先啟動預覽服務，再執行：

```powershell
node find_mom_3d/scratch/qa.cjs
node find_mom_3d/scratch/qa-layout.cjs
node find_mom_3d/scratch/qa-forest.cjs
node find_mom_3d/scratch/qa-journey.cjs
node find_mom_3d/scratch/qa-journey-mobile.cjs
node find_mom_3d/scratch/qa-chapters.cjs
node find_mom_3d/scratch/qa-keepsakes.cjs
node find_mom_3d/scratch/qa-forest-layout.cjs
node find_mom_3d/scratch/qa-action.cjs
```

涵蓋四關完整鍵盤流程、所有謎題、錯誤／提示／暫停／刷新、舊檔升級、不能跳關、過橋安全順序、重玩與儲存失敗，以及手機直向／橫向的觸控與畫面。測試結果及截圖放在 `scratch/`。

尚未做實體手機效能或兒童實玩測試；關卡時間是設計目標，可依孩子反應調整提示、文字與步行距離。

## 新增前情與即時挑戰

- 新遊戲／重玩第一關會播放野餐前情：小米看蝴蝶、風帶來薄霧、與媽媽走散。對話手動翻頁，動畫可暫停或略過；已完成前情的存檔不重播。
- 第二關解完旋律後進入 **疾風小徑**：用左右鍵／A、D，或左右觸控按鈕，閃過六波迎面陣風。前三波單跑道，後三波同時封鎖兩條跑道，第三波後保存進度。
- 再次分開並問路後進入 **風停快跑**：等風停，按住空白鍵／E／畫面的快跑按鈕，到下一座避風亭；放開即停。共有三段，安全時間逐段縮短；每座亭子保存進度。
- 即時挑戰有跑道預警、風勢色彩、剩餘時間、飄葉、樹木搖動和跑步動畫。靜音可玩，減少動態模式停用裝飾搖動，保留必要的移動警示。
- 失誤退回最近安全存點，保留全部旋律與故事進度。各挑戰失誤三次後自動放慢陣風／延長安全時間。暫停及離開視窗會停止挑戰；可選「稍後再試」返回森林。
- 存檔已升級為版本 5（包含版本 4 的前情與即時挑戰進度）。舊檔已重逢或已通關的節點會保留；重玩第二章即可體驗全部新增內容。
- `js/adventure.js` 集中管理前情與即時挑戰；`scratch/qa-action.cjs` 驗證動畫、兩種挑戰、失誤／存點／續玩／暫停、手機控制及舊檔升級。
